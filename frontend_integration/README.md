# Omega Frontend Integration Kit

Use these files to connect an AI Studio or React frontend to the finalized Omega
backend without moving execution logic into the browser.

## Backend URL

Local PM2 backend:

```text
http://127.0.0.1:8080
```

Remote frontend deployment should call an HTTPS reverse proxy that points to the
same backend:

```text
https://your-omega-api.example.com
```

## Environment Variables

```env
VITE_OMEGA_API_URL=http://127.0.0.1:8080
VITE_OMEGA_API_TOKEN=
```

Only set `VITE_OMEGA_API_TOKEN` if the backend has:

```env
API_FRONTEND_TOKEN_REQUIRED=true
API_TOKEN=<same-token>
```

## Files

- `omegaApiClient.ts`: stable typed client for the backend API.
- `useOmegaRuntime.tsx`: polling React hook for status/PnL/traces/proofs.
- `OmegaRuntimePanel.tsx`: operator panel wired to runtime, pool discovery,
  oracle, liquidation, PnL, trace, and validation endpoints.
- `ExecutionManager.ts`: frontend-safe manager facade for AI Studio or React
  actions. It calls backend APIs only; it does not hold keys, fabricate hashes,
  encode executor calldata, or broadcast transactions.

## Integration Rules

- Frontend never receives private keys.
- Frontend never builds or broadcasts raw transactions.
- Frontend only calls backend API endpoints.
- Backend remains responsible for exact-call, fork, adapter, and broadcast gates.
- Live mode remains a backend-guarded runtime state, not a frontend shortcut.
- The finalizer verdict is available at `/api/finalizer/report`; use it as the
  consolidated readiness source for operator UX.
- Do not use browser-side `ethers.Wallet` or generic `executeArbitrage(...)`
  ABI calls. The canonical executor calldata is generated by `omega_v5.execution`.
- Pool discovery cards are telemetry only. A promoted Curve/factory/dynamic pool
  still needs live RPC state, executable liquidity, route-kind adapter coverage,
  and exact-call truth before execution.

## Minimal Usage

```tsx
import { OmegaRuntimePanel } from "./OmegaRuntimePanel";

export default function App() {
  return (
    <OmegaRuntimePanel
      apiBaseUrl={import.meta.env.VITE_OMEGA_API_URL}
      apiToken={import.meta.env.VITE_OMEGA_API_TOKEN}
    />
  );
}
```

## Execution Manager Facade

```ts
import { DeFiExecutorManager } from "./ExecutionManager";

const manager = new DeFiExecutorManager({
  baseUrl: import.meta.env.VITE_OMEGA_API_URL,
  apiToken: import.meta.env.VITE_OMEGA_API_TOKEN,
});

const status = await manager.status(true);
const proof = await manager.validatePipeline(false, 600);
```

`validatePipeline(false)` runs the backend validation with exact-call enabled.
It is still read-only: no frontend signing or broadcast occurs.
